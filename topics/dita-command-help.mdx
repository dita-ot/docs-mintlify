---
title: Accessing help for the dita command
---

You can access a list of subcommands and supported parameters for the `dita` command by passing the **--help** option on the command line.

<Steps>

<Step title="Open a command prompt or terminal session.

">


</Step>

 <Step title="Issue the following command:

">

```
dita --help
```


</Step>

 <Step title="For details on the arguments and options available for each subcommand, pass the
            **--help** option after the subcommand name.

">

For example: `dita install` **--help**.


</Step>


</Steps>



A brief usage summary appears in the command-line window, along with a list of subcommands, arguments, and options.
