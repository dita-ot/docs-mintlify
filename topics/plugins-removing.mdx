---
title: Removing plug-ins
---

Use the `dita uninstall` subcommand to remove a plug-in.

<Steps>

<Step title="At the command-line prompt, enter the following command:

">

```bash
dita uninstall <plug-in-id>
```

where:

-   `*&lt;plug-in-id&gt;*` is the unique ID of the plug-in, as defined in the plug-in’s configuration file \(`plugin.xml`\).

<>

The `uninstall` subcommand also removes the corresponding plug-in directory from the `plugins` folder.
</>




</Step>


</Steps>
