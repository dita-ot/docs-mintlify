---
title: Building output using Ant
---

You can use Ant to run DITA Open Toolkit and generate output. You can use the complete set of parameters that the toolkit supports.

<>

DITA-OT still supports Ant builds, but [the `dita` command](build-using-dita-command.mdx) offers a simpler command interface, sets all required environment variables, and allows you to run DITA-OT without setting up anything beforehand.
</>
