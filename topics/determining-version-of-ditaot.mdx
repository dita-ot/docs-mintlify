---
title: Checking the DITA-OT version number
---

You can determine the DITA Open Toolkit version number from a command prompt.

<Steps>

<Step title="Open a command prompt or terminal session.

">


</Step>

 <Step title="Issue the following command:

">

```
dita --version
```


</Step>


</Steps>



The DITA-OT version number appears on the console:

```
DITA-OT version 4.4.2
```
